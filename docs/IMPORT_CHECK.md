# Чек-лист проверки импорта в DaVinci Resolve Studio 20

Данный документ описывает процедуру импорта автоматически сформированного чернового таймлайна (`timeline.fcpxml` / `timeline.edl`) в DaVinci Resolve Studio 20 (и совместимые версии 18/19), верификацию дорожек и маркеров, а также диагностику возможных проблем.

---

## 1. Подготовка перед импортом

Убедитесь, что в рабочей папке проекта присутствуют следующие файлы:
1. `timeline.fcpxml` (основной таймлайн формата FCPXML 1.9).
2. `timeline.edl` (резервный таймлайн CMX 3600, если экспортировался).
3. `voiceover.wav` или `voiceover.mp3` (цельный файл озвучки сценария).
4. Папка `clips/` со структурой подпапок блоков (`clips/<Блок>/<NN>_<название>.mp4` и `.json` sidecar-файлы).
5. `report.md` (отчёт конвейера с перечнем позиций, требующих внимания).

---

## 2. Пошаговая инструкция импорта

1. **Запустите DaVinci Resolve Studio** и создайте новый проект (или откройте существующий рабочий проект монтажа).
2. **Проверьте настройки частоты кадров проекта**:
   - Нажмите значок шестерёнки в правом нижнем углу (*Project Settings* или `Shift + 9`).
   - Раздел **Master Settings** → **Timeline format**:
     - *Timeline frame rate*: установите то значение, которое указано в листе «Настройки» вашей таблицы (по умолчанию **25 fps**).
     - *Timeline resolution*: **1920 x 1080 HD** (или целевое разрешение из настроек).
   > [!IMPORTANT]
   > В DaVinci Resolve частоту кадров таймлайна нельзя изменить после того, как в проект добавлена первая таймлиния. Убедитесь, что FPS проекта совпадает с FPS из таблицы до импорта.
3. **Импортируйте таймлайн**:
   - В верхнем меню выберите: `File` → `Import` → `Timeline...` (горячие клавиши `Ctrl + Shift + I` на Windows).
   - В открывшемся окне выберите файл `timeline.fcpxml`.
4. **Параметры в окне «Load XML...»**:
   - `Timeline Name`: оставьте по умолчанию (*Skippr Rough Cut*) или задайте своё.
   - `Automatically set project settings`: снимите галочку, если проект уже настроен на нужный FPS, либо оставьте включённой.
   - `Automatically import source clips into media pool`: **Включено** (галочка стоит).
   - Если клипы лежат на внешнем накопителе или пути изменились, включите `Link to source clip files` и укажите путь к папке проекта.
   - Нажмите **OK**.

---

## 3. Что должно появиться на таймлайне (Критерии успеха)

После завершения импорта откройте вкладку **Edit** (`Shift + 4`) и визуально проверьте следующие элементы:

### Дорожка A1 (Озвучка)
- Содержит цельный аудиофайл `voiceover.wav` / `voiceover.mp3`.
- Начало клипа озвучки строго на таймкоде `00:00:00:00` (нулевая секунда таймлайна).
- Аудио воспроизводится непрерывно на всём протяжении ролика.

### Дорожка V1 (Основные видеовставки)
- Содержит нарезанные видеоклипы приоритетов **A** и **B**.
- Видеоклипы не содержат собственных аудиодорожек (звук вырезан ключом `-an`).
- Между клипами присутствуют пустые промежутки (*gap*). В эти места монтажёр добавляет говорящую голову ведущего, титры, анимацию и плашки.
- В местах заглушек (`картинка`, `текст`, `оригинал`) размещены пустые gap-интервалы с информационными маркерами.

### Дорожка V2 (Вспомогательные видеовставки)
- Содержит клипы с приоритетом **C** (альтернативные кадры или наложения поверх дорожки V1).

### Маркеры таймлайна и клипов
На таймлайне расставлены цветовые маркеры:
- **Голубой (Cyan / Chapter)**: Начало каждого смыслового блока сценария (например, `Блок: NVIDIA`).
- **Синий (Blue)**: Начало каждой вставки с номером строки и фразой сценария (`№1: Вопрос зрительницы...`).
- **Красный (Red, `needs_review`)**: Позиции, где выравнивание Whisper имело низкую уверенность, либо фрагмент выбран автодетекцией сцен и требует контроля монтажёра.
- **Оранжевый (Orange, `shortage`)**: Клипы, у которых исходного видео не хватило до целевой длительности.
- **Жёлтый (Yellow, `overlap`)**: Места, где соседние фразы сценария шли слишком плотно и потребовалось автоматическое усечение клипа.
- **Фиолетовый (Purple)**: Заглушки под графику и титры.

### Запас по краям (Handles)
- Активируйте инструмент подрезки **Trim Edit Mode** (клавиша `T`).
- Потяните за левый или правый край любого клипа: у него должен быть запас медиаданных (по умолчанию 1.5 секунды с каждой стороны), позволяющий сделать наплыв (Cross Dissolve) или сдвинуть склейку.

## 4. Типовые проблемы и их решение

### Проблема 1: Клипы красные («Media Offline»)
- **Причина:** Проект был перенесён в другую директорию или на другой логический диск, из-за чего абсолютные пути `file:///` изменились.
- **Решение:**
  1. Выделите клипы в окне **Media Pool** (в левом верхнем углу).
  2. Нажмите правой кнопкой мыши → `Relink Selected Clips...`.
  3. Укажите текущую папку `clips/` на вашем компьютере. Resolve автоматически найдёт все файлы.

### Проблема 2: Рассинхрон звука и видео (клипы сползают к концу таймлайна)
- **Причина:** Частота кадров таймлайна в DaVinci Resolve отличается от настроек конвейера (например, 24 fps вместо 25 fps или 29.97 fps вместо 30 fps).
- **Решение:**
  1. Откройте `report.md` и найдите строку `Частота кадров (FPS)`.
  2. В DaVinci Resolve создайте новую таймлинию: `File` → `New Timeline...` → снимите галочку `Use Project Settings` → вкладка `Format` → установите точный FPS.
  3. Повторите импорт `File` → `Import` → `Timeline...`.

### Проблема 3: «Unable to import timeline» или ошибка парсинга FCPXML
- **Причина:** Специфические региональные настройки или несовместимость версии Resolve с расширенными тегами FCPXML.
- **Решение:**
  1. Воспользуйтесь запасным экспортом в формат CMX 3600 EDL:
     ```bash
     python skippr.py export plan.json --edl -o timeline.edl
     ```
  2. В Resolve выберите `File` → `Import` → `Timeline...` → выберите `timeline.edl`.
  3. При импорте EDL Resolve запросит папку с исходными клипами — укажите папку `clips/`.

### Проблема 4: Клип воспроизводится с ускорением или замедлением
- **Причина:** Сработала политика компенсации нехватки хронометража `slow`. В соответствии с архитектурным решением skippr, замедление запекается ffmpeg прямо в видеофайл с сохранением целевого FPS (без нестабильных тегов ретайминга в FCPXML).
- **Диагностика:** Откройте соответствующий `.json` sidecar рядом с клипом и сверьте поле `speed`.

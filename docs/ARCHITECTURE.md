# Архитектура skippr: Конвейер автомонтажа для DaVinci Resolve

Документ описывает устройство системы `skippr`, анализ существующего ядра `grab.py` и план расширения репозитория до конвейера автомонтажа черновика (Rough Cut) на базе FCPXML для DaVinci Resolve Studio 20.

---

## 1. Анализ существующего `grab.py` (v4.1)

### 1.1 Что есть и как работает
1. **Чтение источников (`load_items`, `XlsxSync`)**:
   - Поддерживает форматы `.xlsx`, `.csv`, `.txt`, прямые URL и поисковые запросы.
   - Поиск колонок через словарь `ALIASES` (автодетект синонимов названий колонок: `№`, `Блок`, `Момент сценария`/`Название`, `Поисковый запрос`, `Таймкод`, `Статус`, `Приоритет`).
   - `XlsxSync` производит двустороннюю синхронизацию с Excel: добавляет колонки `Статус`, `Ссылка (выбрано)`, `Файл`, `Заметка`, красит статусы («скачано» — зеленый, «ошибка» — оранжевый). Если файл открыт в Excel, безопасно пишет в `*_results.xlsx`.
2. **Парсинг таймкодов (`parse_tc`, `parse_point`)**:
   - Робастный парсер диапазонов: `1:23-1:40`, `85-110`, `0:45+15s`, а также поддержка типов `datetime.time`, `datetime.timedelta` и чисел из Excel.
3. **Поиск и выбор кандидатов (`search`, `choose`)**:
   - Поиск через flat-экстракцию `ytsearch{2*results}:{query}`.
   - Фильтрация: отклонение стримов (`live`), вертикальных `Shorts`, роликов длиннее `--max-min` минут (по умолчанию 20) без таймкода.
   - Интерактивный режим `--pick` или автовыбор первого подходящего.
4. **Загрузка и нарезка (`ydl_download`, `process`, `encode`)**:
   - Два режима: `full` (скачивание в кэш + точная нарезка через FFmpeg) и `section` (скачивание диапазона через `download_ranges` с маржой).
   - `encode`: нормализация в H.264 (`libx264`), yuv420p, `-preset veryfast`, `-crf 18`, звук AAC 192k, `+faststart`.
   - Проверка валидности полученного файла через `ffprobe` (`is_valid`, `probe`).
5. **Организация файлов**:
   - Клипы раскладываются по папкам блоков: `<out>/<Блок>/<NN>_<момент>.mp4`.
   - Кэш хранится в `.cache`.

### 1.2 Что сохраняется без изменений
- Полная обратная совместимость со старыми таблицами (включая [montazhny_list_opensorsa.xlsx](file:///c:/Users/azis/Desktop/downoalder/montazhny_list_opensorsa.xlsx)).
- Логика двусторонней синхронизации с Excel (`XlsxSync`) и обработка блокировки файла Excel.
- Скачивание через `yt-dlp` с перекодированием в H.264 (`libx264`, `yuv420p`, `-preset veryfast`).
- Система логирования через `Tee` и консольный прогресс.

### 1.3 Что модифицируется и добавляется в `grab.py`
1. **Интерфейс загрузчика (`Downloader`)**:
   - Выделение абстракции загрузчика для подмены на локальные видео в автотестах (без обращения к YouTube).
2. **Ветвление по колонке `Вид` (`kind`)**:
   - `клип` — стандартное скачивание.
   - `картинка`, `оригинал`, `текст` — пропуск скачивания, создание заглушки для плана таймлайна.
3. **Удаление звука у клипов (`-an`)**:
   - Вставки в проекте лежат поверх озвучки; клипы на таймлайне не должны содержать аудиодорожки.
4. **Нарезка с запасом (`handle_sec`) и приведение к `fps` проекта**:
   - Видео нарезается с запасом `handle_sec` (по умолчанию 1.5 с) с обеих сторон для возможности монтажной подгонки в DaVinci Resolve.
   - Перекодирование с явным `-r {fps}` для строгой синхронизации с сеткой кадров проекта.
5. **Генерация sidecar-файлов `<файл>.json`**:
   - Рядом с каждым клипом сохраняется метаинформация:
     ```json
     {
       "source_in": 12.5,
       "source_out": 22.5,
       "useful_in": 1.5,
       "useful_out": 8.5,
       "handle_in": 1.5,
       "handle_out": 1.5,
       "src_url": "https://...",
       "src_fps": 25.0
     }
     ```
6. **Стратегия для клипов без таймкода**:
   - Скачивание полного ролика в кэш.
   - Шаг 1: если есть субтитры и в `Референсе` или `Заметках` найдена цитата в кавычках `«...»` или `"..."` — поиск по субтитрам.
   - Шаг 2: детекция сцен через `PySceneDetect` (`ContentDetector`), выбор наиболее длинной непрерывной сцены $\ge$ требуемой длительности.
   - Шаг 3: фоллбэк на фрагмент с 10-й секунды с выставлением флага `needs_review`.

## 2. Общая схема конвейера skippr

```
[montazhny_list.xlsx] ──► [validate.py] ── (проверка схемы, ссылок, текста)
       │                        │
       ▼                        ▼
[script.txt] + [voiceover.wav] ──► [align.py] ──► [phrases.json] (якоря времени в звуке)
       │                                                 │
       ▼                                                 ▼
[grab.py] ──► [clips/...] + [<clip>.json sidecars] ──► [plan.py] ──► [plan.json]
                                                                         │
                                                                         ▼
                                                                [export_fcpxml.py]
                                                                         │
                                                                         ▼
                                                                [timeline.fcpxml]
                                                                 (DaVinci Resolve)
                                                                         +
                                                                   [report.md]
```

## 3. Модули системы

### 3.1 `skippr_core/` (Ядро общего назначения)
- `config.py`: чтение листа «Настройки» и CLI-параметров с дефолтами.
- `table.py`: универсальный загрузчик таблиц (`new_template` vs `legacy_opensorsa`), приведение к единой внутренней модели `RowItem`.
- `models.py`: датаклассы / Pydantic-схемы для `RowItem`, `PhraseAnchor`, `PlanItem`, `SidecarData`.
- `fps.py`: строгая арифметика кадров и секунд без накопления ошибки округления.

### 3.2 `make_template.py` (Задача 0)
- Генерация нового чистого шаблона `montazhny_list.xlsx` через `openpyxl`.
- Лист «Монтажный лист» с валидацией выпадающих списков:
  - `Вид`: `клип`, `картинка`, `оригинал`, `текст`.
  - `Приоритет`: `A`, `B`, `C`.
  - `Статус`: `найти`, `скачано`, `ошибка`, `пропуск`.
- Лист «Настройки» с ключами и значениями по умолчанию.
- Лист «Легенда» с пояснениями колонок.

### 3.3 `validate.py` (Модуль 1)
- Валидация входных данных до запуска тяжелых процессов.
- Проверки:
  - Уникальность `№`.
  - Обязательные поля: `Блок`, `Фраза`, `Вид`, `Длительность, с`.
  - Корректность списочных значений.
  - Поиск `Фразы` в `script.txt` (с нормализацией регистра, знаков препинания, ё/е).
  - Парсинг `Таймкод (от-до)`.
- Табличный вывод ошибок и предупреждений, ненулевой код возврата при критических ошибках.

### 3.4 `align.py` (Модуль 2)
- Транскрибация `voiceover` с помощью `faster-whisper` с посекундными метками слов (`word_timestamps=True`).
- Кэширование расшифровки в `cache/transcript.json`.
- Двухуровневый матчинг фразы:
  1. Точный поиск последовательности нормализованных токенов.
  2. Нечеткий скользящий поиск через `rapidfuzz` (fuzzy partial token match) с порогом уверенности.
- Гарантия монотонности: якоря строк не могут быть раньше предыдущих.
- Поддержка ручного переопределения через `anchors_override.json` или колонку в таблице.
- Выгрузка `phrases.json`.

### 3.5 `plan.py` (Модуль 4)
- Формирование плана монтажного таймлайна `plan.json`.
- Расчет `timeline_start = anchor_start + Смещение`.
- Обработка нехватки длительности по `shortage_policy` (`slow`, `gap`, `flag`).
- Обработка пересечений клипов: подрезка предыдущего клипа не ниже 0.5 с или выставление флага `overlap`.
- Распределение по дорожкам: Приоритет C -> `V2`, остальные -> `V1`.
- Заглушки для `картинка`, `оригинал`, `текст` -> маркеры и gap-клипы.
- Синхронное хранение времени в секундах (`float`) и кадрах (`int`) с квантованием по сетке кадров.

### 3.6 `export_fcpxml.py` (Модуль 5)
- Формирование XML формата FCPXML 1.9 для DaVinci Resolve Studio 20.
- Дорожка A1: полная озвучка с 0:00.
- Дорожка V1: клипы без звука, разделенные `<gap>`.
- Дорожка V2: клипы приоритета C.
- Маркеры блоков, номеров строк и проблемных участков (`needs_review`, `shortage`, `overlap`, `placeholder`).
- Корректное URI-кодирование Windows-путей (`file:///C:/...`).
- Валидация XML перед записью.

### 3.7 `skippr.py` (Единый CLI)
Команды:
- `skippr template [-o path]`
- `skippr validate <table.xlsx> [--script script.txt]`
- `skippr align <table.xlsx> [--voiceover path] [--script path]`
- `skippr grab <table.xlsx> [-o out_dir]`
- `skippr plan <table.xlsx> [-o out_dir]`
- `skippr export <plan.json> [-o timeline.fcpxml]`
- `skippr all <table.xlsx> [-o out_dir]`

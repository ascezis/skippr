# План улучшений и бэклог идей (IMPROVEMENTS.md) 🚀

Данный документ фиксирует архитектурные идеи, улучшения пайплайна и фичи для будущих версий **skippr**, родившиеся в ходе боевого тестирования конвейера.

---

## 🌟 1. Полноценная система бэкапа исходников (Source Footage Archive)

### Проблема:
* Сейчас полные исходники роликов сохраняются в техническую папку `clips/_cache/` под обезличенными YouTube ID (`GBvBu5ErSSo.mp4`, `l9EzK-719aE.mp4`).
* Для человека и монтажёра слово «кэш» звучит как временный мусор, который можно случайно удалить.
* Если монтажёру в DaVinci Resolve не хватило 3–4 секунд нарезанного клипа и захотелось взять из фильма/сцены другие 20–30 секунд (или взять оригинальную аудиодорожку сцены), ему приходится вручную искать ролик на YouTube или гадать, какой хеш в `_cache` какому фильму соответствует.

### Решение: Выделенная папка `sources/` (или `backup/`)
1. **Человекочитаемая структура хранения:**
   Полные исходные видео сохраняются параллельно с нарезкой в понятную иерархию:
   ```text
   montage/
   ├── clips/                         # Нарезанные короткие фрагменты (+1.5 с handles)
   │   └── Git_BitKeeper/
   │       ├── 25_гонку_проиграл.mp4
   │       └── 25_гонку_проиграл.mp4.json
   └── sources/                       # Полные нетронутые исходники
       └── Git_BitKeeper/
           └── 25_Выступление_Линуса_Google_FULL.mp4
   ```
2. **Связь в JSON-сайдкаре:**
   Рядом с каждым нарезанным клипом в `.json` сайдкар прописывается прямой путь к полному исходнику:
   ```json
   {
     "source_file": "sources/Git_BitKeeper/25_Выступление_Линуса_Google_FULL.mp4",
     "source_duration": 754.2,
     "source_in": 124.5,
     "source_out": 128.5,
     "useful_in": 1.5,
     "useful_out": 4.5
   }
   ```
3. **Импорт отдельным бином в DaVinci Resolve:**
   В `timeline.fcpxml` исходники из папки `sources/` добавляются в отдельную папку пула медиа (*Media Pool Bin: «Полные исходники»*). Монтажёр видит их прямо в Resolve и может вытащить любой фрагмент за 2 секунды.
4. **Команда быстрого Re-trim (перенарезки):**
   Если длительность в таблице изменена (например, с 3 с на 15 с), команда `python skippr.py grab --redo --only 25` моментально режет новый кусок из локального `sources/` без обращения к интернету.

## 🎙️ 2. Автоматический пре-мастеринг аудио и разметка брака (`prep_audio.py`) — ✅ ЧАСТИЧНО РЕАЛИЗОВАНО

### Реализовано в v1.1 (`prep_audio.py` / `skippr prep-audio`):
* **Двухпроходная нормализация EBU R128 (-14.0 LUFS, True Peak -1.0 dBFS):**
  * Первый проход: замер реальной громкости, пиков и динамики LRA.
  * Второй проход: чистая линейная подгонка (`linear=true`) без искажения тембра и динамики. Исходный файл из FL Studio не перезаписывается.
* Интегрировано флагом `--normalize-lufs` в команды `skippr align` и `skippr all`.

### В планах бэклога:
1. **Студийный фильтр высоких частот (High-pass 80 Hz):** опциональный срез низкочастотного гула стола.
2. **Детекция дублей через Whisper:** пословное сравнение повторяющихся цепочек слов с расстановкой красных маркеров `[ДУБЛЬ]` в DaVinci Resolve.
3. **Детекция аномальных пауз:** выявление пауз длиннее 1.5–2.0 секунд.

## 🤖 3. Прямая генерация монтажного листа через AI (`skippr analyze-script`)

### Проблема:
Сейчас пользователь копирует текст сценария в веб-чат Claude/ChatGPT с системным промптом из [docs/AI_CUE_SHEET_SPEC.md](AI_CUE_SHEET_SPEC.md), получает Markdown-таблицу и вставляет её в Excel.

### Решение:
Встроить генерацию напрямую в CLI через API:
```powershell
python skippr.py analyze-script script.txt -o montazhny_list.xlsx --model claude-3-7-sonnet
```
* Скрипт отправляет сценарий по API, валидирует дословность цитат через `validate.py` «на лету» и сразу сохраняет валидный `.xlsx` с заполненными выпадающими списками и формулами.

## 🔊 4. Умный Ducking (приглушение звука B-roll)

### Проблема:
Сейчас все видеоклипы режутся с ключом `-an` (аудио удаляется полностью), чтобы шум клипа не мешал голосу. Однако иногда в клипе важен оригинальный звук (знаменитая фраза героя, звук мотора, рёв толпы).

### Решение:
* Добавить в таблицу опциональную колонку «Звук клипа»: `вырезать` (по умолчанию), `оставить`, `фоном (-18dB)`.
* В FCPXML для клипов со звуком автоматически выставлять уровень громкости и аудио-дорожку A2, приглушаемую под голос диктора (Auto Ducking).

## 🖥️ 5. Легковесный Web-интерфейс предпросмотра (Review UI)

### Проблема:
Перед запуском импорта в Resolve иногда хочется бегло «прокликать» скачанные клипы и убедиться, что найдены правильные моменты фильмов.

### Решение:
Команда `python skippr.py ui` поднимает локальный легковесный веб-сервер на 1 страницу:
* Таблица со статусами и превью клипов прямо в браузере.
* Возможность в один клик забраковать клип и ввести другой поисковый запрос.
* Кнопка «Собрать проект для Resolve».

# skippr 🎬⚡

> **Конвейер автомонтажа чернового таймлайна для DaVinci Resolve Studio 20.**
> Превращает монтажный лист, цельную озвучку и текст сценария в готовые B-roll клипы с запасом по краям, привязывает их к таймкодам речи и генерирует импортируемый таймлайн `timeline.fcpxml`.

## 💡 Что делает skippr

Входные данные:
- **`montazhny_list.xlsx`** — монтажный лист с фразами сценария, длительностями и поисковыми запросами.
- **`voiceover.wav`** (или mp3) — цельная дорожка начитки диктора.
- **`script.txt`** — полный текст сценария, идентичный озвучке.

Выходные данные:
- **`clips/<Блок>/<NN>_<название>.mp4`** — нормализованные H.264 видеоклипы без звука с запасом по краям (`handle_sec`, 1.5 сек) под склейки и переходы.
- **`<клип>.json`** — sidecar-метаданные с границами полезного фрагмента (`useful_in/out`), исходным FPS и URL.
- **`phrases.json`** — синхронизация фраз со звуковой дорожкой на основе word-level таймкодов Whisper.
- **`plan.json`** — рассчитанный таймлайн с квантованием по кадрам сетки проекта.
- **`timeline.fcpxml`** — таймлайн FCPXML 1.9 для мгновенного импорта в DaVinci Resolve Studio 20 (дорожка A1 с голосом, V1 с основными клипами, V2 для приоритета C, маркеры блоков, номеров строк и предупреждений).
- **`report.md`** — детальный отчёт о сборке с выделением моментов, требующих внимания монтажёра.

Вставки располагаются поверх озвучки в точных местах соответствующих реплик, оставляя промежутки под графику, титры и ведущего.

## 🛠️ Установка

### 1. Системные зависимости
- **Python 3.10+** (протестировано на 3.12, Windows 11)
- **ffmpeg** и **ffprobe** в системном `PATH`
- **Deno** (для обхода JS-челленджей YouTube):
  ```powershell
  winget install DenoLand.Deno
  ```

### 2. Установка Python-пакетов
```powershell
pip install -r requirements.txt
```

## 🚀 Быстрый старт: Единый CLI (`skippr.py`)

### Полный прогон конвейера в одну команду
```powershell
python skippr.py all montazhny_list.xlsx
```
Флаги:
- `--dry-run`: симуляция работы без реального скачивания видео (проверяет таблицу, сценарий, таймлайн и генерирует отчёт).
- `--force`: принудительный пересчёт кэша транскрибации Whisper и выравнивания.
- `--only 1,3-5`: обработка только указанных строк таблицы.
- `--edl`: дополнительно сгенерировать резервный таймлайн `timeline.edl` (CMX 3600).
- `-o <папка>`: целевая рабочая папка проекта.

## 🧩 Модули и пошаговый запуск

Каждый этап конвейера можно запускать отдельно:

### 0. Создание чистого шаблона таблицы
```powershell
python skippr.py template -o montazhny_list.xlsx
```
Создаёт файл Excel с выпадающими списками (*клип/картинка/оригинал/текст*, *найти/скачано/ошибка/пропуск*), валидацией, фильтрами, листом «Настройки» и «Легенда».

### 1. Валидация перед запуском (`validate.py`)
```powershell
python skippr.py validate montazhny_list.xlsx --script script.txt
```
Проверяет:
- Уникальность номеров `№`.
- Обязательные непустые поля (Блок, Фраза, Вид, Длительность).
- Вхождение каждой фразы в текст сценария `script.txt` (с нормализацией регистра, знаков препинания и ё/е).
- Корректность синтаксиса таймкодов.

### 2. Выравнивание фраз по звуку (`align.py`)
```powershell
python skippr.py align montazhny_list.xlsx --voiceover voiceover.wav
```
- Транскрибирует аудио через `faster-whisper` с word-level timestamps (CUDA при наличии, иначе CPU int8).
- Кэширует результат в `cache/transcript.json`.
- Сопоставляет фразы: точный поиск по нормализованным токенам -> нечёткий поиск (fuzzy sliding window через `rapidfuzz`).
- Обеспечивает строгую монотонность якорей во времени.
- Поддерживает ручные правки через `anchors_override.json` (`{"1": 12.5}`).

### 3. Сбор и нарезка видео (`grab.py`)
```powershell
python skippr.py grab montazhny_list.xlsx -o clips
```
- Игнорирует не-видео строки (`картинка`, `текст`, `оригинал`) для таймлайна-заглушек.
- Автоматически нарезает с запасом `handle_sec` (по умолчанию 1.5 с) с обеих сторон.
- Вырезает аудиопоток (`-an`), перекодирует в H.264 `yuv420p` к `fps` проекта.
- Для клипов без таймкода: поиск цитаты в субтитрах -> детекция сцен через `PySceneDetect` -> запасной фрагмент с 10-й секунды.
- Создаёт JSON-сайдкары с метаданными.

### 4. Расчёт плана монтажа (`plan.py`)
```powershell
python skippr.py plan montazhny_list.xlsx --phrases phrases.json --clips clips
```
- Квантует все таймкоды строго по сетке кадров проекта без накопления погрешностей.
- Разрешает нехватку хронометража по цепочке `shortage_policy` (`slow` -> `gap` -> `flag`). Замедление запекается через ffmpeg без нестабильных тегов в XML.
- Разрешает наложения и пересечения: усечение клипа до минимума 0.5 с или флаг `overlap`.
- Направляет клипы приоритета C на вторую дорожку `V2`.

### 5. Экспорт в DaVinci Resolve (`export_fcpxml.py` / `export_edl.py`)
```powershell
python skippr.py export plan.json -o timeline.fcpxml --table montazhny_list.xlsx --edl
```
- Формирует валидный файл `timeline.fcpxml` (версия FCPXML 1.9).
- Дорожка A1: цельная озвучка с 00:00:00:00.
- Дорожка V1: клипы и gap-интервалы.
- Дорожка V2: B-roll приоритета C.
- Цветовые маркеры блоков, строк и предупреждений (`needs_review`, `shortage`, `overlap`).
- Генерирует `report.md`.

## 📥 Импорт в DaVinci Resolve Studio

1. Откройте DaVinci Resolve Studio и создайте проект.
2. В **Project Settings** (`Shift + 9`) убедитесь, что **Timeline frame rate** совпадает с настройками таблицы (по умолчанию **25 fps**).
3. Выберите в меню: `File` → `Import` → `Timeline...` (`Ctrl + Shift + I`).
4. Выберите файл `timeline.fcpxml`.
5. Пошаговый чек-лист и устранение типовых проблем описаны в [docs/IMPORT_CHECK.md](docs/IMPORT_CHECK.md).

## ⚠️ Известные ограничения

1. **Без прямого API Resolve:** Управление Resolve осуществляется исключительно через стандартные файлы обмена (`timeline.fcpxml` и `timeline.edl`). Это гарантирует независимость от версии Resolve, закрытых скриптовых лицензий и платформы.
2. **Фиксация частоты кадров (FPS):** DaVinci Resolve блокирует изменение FPS таймлайна после добавления первых клипов. FPS в листе «Настройки» таблицы должен совпадать с FPS проекта в Resolve до импорта.
3. **Запекание замедления (Retiming):** При нехватке хронометража замедление (`min_speed` 0.8) запекается через ffmpeg прямо в видеоклип с сохранением проектного FPS. В FCPXML не используются теги динамического ретайминга, так как разные версии Resolve интерпретируют их непредсказуемо.
4. **Аппаратное ускорение Whisper:** Для высокой скорости распознавания длинных аудиодорожек рекомендуется видеокарта с поддержкой NVIDIA CUDA. При отсутствии CUDA конвейер автоматически переключается на CPU с оптимизацией `int8`.
